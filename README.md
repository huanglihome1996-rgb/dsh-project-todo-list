# 项目待办（DSH 本地插件）

仅在已选项目工作区、尚未发送第一条消息的新会话输入框下展示待办。扫描 README、计划、需求、任务文档及 GitHub 未关闭 Issue，并调用当前 DSH 默认 AI 模型，根据任务前后的原文判定：**明确属于当前用户、尚未完成、需要由其执行的具体下一步**才显示。仅提及、抄送或 `@` 用户、任务归属不明及 AI 判断失败均不显示；模型输出必须给出在原文中可验证的归属与动作证据。点击任务仅填入推荐提示词，不会发送消息。

插件会将最多 60 个候选项分批提交至当前配置的模型进行判断；项目文档原文会发往该模型服务，请按项目保密要求使用。可在配置中指定 `provider` 与 `model`。刷新与完成状态仅保存在 `$DSH_HOME/project-todo/`（默认 `~/.dsh/project-todo/`），不会写入项目仓库。GitHub Issue 仅在本机已安装且登录 `gh`，且项目 remote 指向 GitHub 时读取；无法访问时仅分析本地文档。身份由项目 Git 用户名/邮箱、GitHub 登录名及可选 `name`、`aliases` 配置交叉确认。
